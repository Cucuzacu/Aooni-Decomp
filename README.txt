Aooni
("Aooni" means "Blue Demon")
ver.6.23

Controls

Movement		Arrow Keys, 2,4,6,8
Cancel, Display Menu	X, Esc, 0
Select, Inspect		C, Enter, Space
Display in Full-Screen	Alt+Enter
Close Application	Alt+F4
Title			F12
Properties		F1

In order to play this game you need to install the RPG MAKER XP RTP
You can download it from the link below.
http://www.rpgmakerweb.com/download/run-time-package#xp

*Strategy Hints*

When the enemy is following you
 You can not pick up items
 You can not open the menu
 You CAN open locked doors
You can lose the enemy by running for a certain amount of time,
or hiding in closets around the game.
